# Domain Verticals — Quectosoft Technologies LLP

**Author:** Subrit Dikshit <subrit@quectosofttech.com>

## Supported Verticals

### BFSI — Banking, Financial Services & Insurance
- **RBI Compliance Agent**: RBI 2026 guidelines, tokenisation, KYC norms
- **SEBI Analyst Agent**: SEBI LODR, ESOP reporting, insider trading checks
- **CKYC Verification Agent**: Central KYC registry integration, de-duplication

### Telecom
- **OSS/BSS Agent**: Network inventory, billing systems, provisioning automation
- **5G Architecture Agent**: 5G NR design, core network slicing, RAN planning

### Healthcare
- **HIPAA Compliance Agent**: PHI handling, audit trails, breach notification
- **HL7/FHIR Agent**: HL7 v2/v3 parsing, FHIR R4 resource mapping, EHR integration

### Retail
- **E-Commerce Agent**: Catalogue management, order processing, inventory sync

### GovTech
- **Policy Agent**: Government procurement rules, regulatory documentation, RTI compliance

All domain agents run with tighter RAID thresholds (HITL from score 15, not 20)
and require C-Suite approval from score 10 (not 13).
