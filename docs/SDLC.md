# SDLC Pipeline — Quectosoft Technologies LLP

**Author:** Subrit Dikshit <subrit@quectosofttech.com>

## Autonomous SDLC Phases

| Phase | Agent | Output |
|---|---|---|
| 1. Requirements | requirements_agent | PRD, user stories, acceptance criteria |
| 2. Design | architect_agent | Architecture ADR, system design doc, API contracts |
| 3. Engineering | developer_agent ×N | Source code, unit tests, PR |
| 4. QA | qa_engineer_agent ×N | Test reports, bug reports, regression suite |
| 5. Security | security_eng_agent | SAST report, pentest findings, CVSS scores |
| 6. DevOps | devops_engineer_agent | CI/CD pipeline, infra-as-code, deployment |
| 7. Docs | tech_writer_agent | API docs, runbooks, deployment guide |

## Safety Gates

- All code generated by agents runs in isolated Dockerfile.sandbox containers
- Bandit + Semgrep + Sage scan every PR before merge
- Security agent reviews every PR with CVSS ≥ 7 before devops deploys
